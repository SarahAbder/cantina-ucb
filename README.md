# cantina-ucb
Sistema de pedidos para uma cantina, desenvolvido em C como atividade acadêmica de Lógica de Programação na UCB.

## Funcionalidades

- Exibição do cardápio
- Registro de pedidos
- Cálculo do valor total da compra
- Aplicação das regras propostas na atividade
- Exibição do resumo do pedido

## Tecnologias

- Linguagem C
- OnlineGDB

## Objetivo

O projeto tem como objetivo aplicar conceitos básicos de programação em C estudados durante a disciplina, como estruturas condicionais, estruturas de repetição, funções e entrada e saída de dados.
